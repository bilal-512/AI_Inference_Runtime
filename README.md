# AI Inference Runtime

A lightweight C++ inference runtime for building and executing small neural-network-style computation graphs. The project is organized around tensors, nodes, graphs, and operators, making it a simple foundation for experimenting with inference pipelines and model execution in native C++.

## Overview

This project provides:

- A tensor container with shape and stride handling
- A graph and node abstraction for composing operations
- Execution planning and validation support
- A model abstraction for parameters and graph state
- Operator implementations for common neural-network layers

## Supported operators

The runtime includes implementations for:

- Add
- ReLU
- MatMul
- Softmax
- LayerNorm
- GELU

## Build instructions

This project uses CMake and C++17.

### 1) Configure the project

```bash
mkdir -p build
cd build
cmake ..
```

### 2) Build targets

```bash
cmake --build .
```

This will build the core runtime library along with the example and test executables defined in `CMakeLists.txt`.

## Run the project

After building, the generated executables are available in the `build` directory.

Typical examples:

```bash
./runtime
./tensor_example
```

Individual test binaries are also created, for example:

```bash
./tensor_test
./add_test
./relu_test
./matmul_test
./softmax_test
```

## Core components

### Tensor
The `Tensor` class stores tensor shape, stride information, and data. It supports indexed access and provides the basic storage primitive for graph input and intermediate values.

### Node
A `Node` represents a computation unit or operation in the graph. Nodes are connected to form a dependency graph.

### Graph
The `Graph` class manages nodes and connectivity, validates graph structure, and produces execution ordering.

### Executor
The `Executor` is responsible for evaluating the graph in a valid execution order and applying operators to data.

### Model
The `Model` class wraps graph structure and parameter storage for higher-level inference workflows.

## Example usage

A minimal usage pattern is:

```cpp
// Create tensors and build a graph
// Add nodes for operations such as matmul, relu, softmax, etc.
// Connect nodes according to data flow
// Execute using the runtime graph / executor
```

This project is designed as a simple educational and experimental inference runtime rather than a full production ML framework.
